So bekommst du den Anthropic-API-Key
  1. Claude-Konsole → API Keys öffnen und anmelden (console.anthropic.com leitet dorthin weiter).
  2. „Create Key“ klicken, Name z. B. immobot.
  3. Key sofort kopieren – er wird nur einmal angezeigt – und hier einfügen.

Ohne Guthaben funktioniert der Key nicht: in derselben Konsole unter Billing Guthaben aufladen und am besten ein Limit setzen.

{% elif name == "deutschlandgpt_api_key" %}
So bekommst du den DeutschlandGPT-API-Key
  1. DeutschlandGPT Platform-API öffnen und anmelden (der Workspace wird beim ersten Aufruf angelegt).
  2. Guthaben: unter Billing „Purchase Credits“.
  3. Key: unter API-Keys „Add API key“, Name z. B. immobot, optional ein Ausgabenlimit.
  4. Key sofort kopieren – er ist nur einmal sichtbar – und hier einfügen.
{% elif name == "telegram_bot_token" %}
So bekommst du den Bot-Token
  1. In Telegram @BotFather öffnen.
  2. Bestehender Bot (derselbe wie in Fredys Telegram-Adapter): /mybots → Bot wählen → „API Token“.
    Neuer Bot: /newbot senden, Name und Benutzername wählen (endet auf „bot“).
  3. Token kopieren und hier einfügen. Für eine Gruppe: Bot in die Gruppe einladen.

Wer den Token hat, steuert den Bot – nicht weitergeben. Neu erzeugen geht beim BotFather mit /revoke.

{% elif name == "telegram_chat_id" %}
So bekommst du die Chat-ID
  1. Am einfachsten: „Chat per Code verbinden“ (unter „Ändern“) – der Bot trägt Chat-ID und deine User-ID selbst ein.
  2. Manuell: dieselbe ID wie in Fredys Telegram-Adapter. Gruppen-IDs sind negativ (z. B. -100…).
{% elif name == "telegram_allowed_user_ids" %}
So bekommst du deine User-ID
  1. Wird beim Pairing („Chat per Code verbinden“) automatisch eingetragen.
  2. Manuell: @userinfobot öffnen und „Start“ drücken – die angezeigte Id ist deine User-ID. Mehrere IDs mit Komma trennen.
{% elif name == "fredy_webhook_token" %}
So richtest du den Webhook in Fredy ein
  1. Hier unter „Ändern“ auf „Neu erzeugen“ klicken – der Token wird genau einmal angezeigt.
  2. In Fredy den Job öffnen → Benachrichtigungen (Notification Adapter) → Adapter „HTTP“ hinzufügen.
  3. Endpoint URL: {{ hook_url }}
  4. Auth Token: den Token einfügen und speichern.
